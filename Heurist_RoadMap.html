Heurist RoadMap

This page describes planned new features and development priorities for the Heurist software ( HeuristNetwork.org ).

This diagram represents the main priorities set following the workshop at Beaumes de Venise in April 2023.
Unfortunately progress has been delayed due to administrative issues and significant work on improvements to
security and maintainability in preparation for transition to a community organisation in 2025 or 2026.
For each section likely development order runs from left to right, but the order may change as users/projects
request or dictate. This does not cover routine maintenance, small interface improvements and bug fixing.

Further information to be provided later.
