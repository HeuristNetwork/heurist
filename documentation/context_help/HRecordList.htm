HEURIST Help

HRecordList is the main widget to represent your data

Usage

HRecordList is intended to display the list of records from your database. It can be used as a main tool to discover of your database data or as a helper widget for list of sponsors, social network links or team memebrs.

This list may be a result of filter execution obtained from other widget (see HFilter), the selected records (for example on map), or result of initial interna filter (defined as an option).

Presentation

Each record is presented as an item/card. Cards can be arranged as grid or vertical or horizontal list. The size of card is specified by its content

The record list can be paginated. Navigation buttons will be added into header of widget.

It is possible to define custom messages/placeholders for initial state and empty result set.

Content of record's item

Record card can be rendered by internal function or by using (smarty) template. You can select among predefined build-in or user's templates. Build-in templates can be modify and saved into common user's templates folder.

HTML element for record have must have attribute 'data-heurist-rec' with record ID value and class 'recordList-item'

Actions

Need to define what is default action when user clicks on record's card: none, trigger select event or open record view.
