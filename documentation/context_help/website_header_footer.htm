Define website header and footer
Where are configuration settings

In Site menu treeview select Header or Footer items. They are just below "Home page"

Select template

First of all you may select the template. There are several ones to choose. Warning if you already modify the header or footer your changes will be lost

Define behaviour

Define scroll and visibility behaviour. Your header or footer can be sticked (always visible), scrollable (default option), collapsable or hidden at all

Define styles

You can define the standard set of styles for background, border and margins

Define widget options

Header and footer have the default set of widgets: Menu, Personal, Brands. Besides you can add any other widget from Heurist set. Such as Search or Contact Us forms. To change widget appearance and behaviour select it in Page treeview and set options in a form.

Direct edit of content

The HTML content can be modified directly. You may define static values for elements (such as website title or background image url). Or these values can be obtained from Website Home record or generated from system settings. The latter approach gives you more flexibility for updating content and a single place to edit many values.

The dynamic values in content are defined in Smarty format: {$website.[name of variable]}. Here is the list of available variables:

  • title - title of website (field# 2-1)
  • titleAlt1 - alternative title of website (3-1009)
  • titleAlt2 - alternative title of website (3-1052)
  • logo - main logo image (2-38)
  • logoAlt - alternative logo (2-926)
  • url - url of website (home page)
  • urlAlt - additional url (2-943)
  • bgImage - background (banner) image (99-951)
  • languages - selector with list of languages (2-967)
  • showLogin - returns "block" or "none" to show or hide suppress personal menu widget (login and edit website) (2-1095)
  • navbar - generates site map - list of links. Use as a content for HMenu widget
  • hostInfo - logo and information of Heurist hosting (defined in system settings)
  • heuristInfo - Heurist logo and info
