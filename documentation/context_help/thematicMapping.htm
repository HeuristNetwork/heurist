Thematic Renderers

Thematic renderers change the appearance of records on a map according to the values of one or more record fields. For example, a field such as Country can control colour, Population can control symbol size, and City type can control the marker symbol.

Opening the thematic map editor

Open the symbology editor for a map layer and choose the thematic renderers option. A map layer may contain several thematic renderer definitions. A new definition starts with no renderer. Use Add renderer to create one, then use the pencil or bin icons in the renderer list to rename or remove it.

Thematic renderer settings

  • Title — the name displayed for this thematic renderer. Titles must be unique within the layer.
  • Active by default — makes this renderer active when the map layer is first loaded. Only one renderer can be active by default; if none is active, the layer uses its default symbology.
  • Base symbol — optional symbology applied before field-specific rules. Click the symbol sample or Edit to modify it. Use Reset to inherit the layer's normal symbology.

A thematic renderer can override only the properties that need to change. Any property not specified by the thematic map continues to use the base symbol or the normal layer symbology.

Selecting fields

The Fields list contains the fields used by the selected thematic renderer. If no field has yet been selected, the field-selection area is displayed automatically. Choose a record type represented in the layer, then select a field from the record structure. If the layer contains only one record type, it is shown directly instead of displaying a selector.

After at least one field has been added, the field-selection area is hidden to leave more space for editing ranges and categories. Click Add field whenever you need to add another field.

Several fields may contribute different parts of the final symbol in the same renderer. For example, one field can determine colour, another can determine size, and another can determine the icon.

Defining ranges and categories

Select a field in the Fields list to edit its ranges or categories. The field Title can be changed to a more suitable label for use in the thematic renderer.

  • Add range — adds a range or category manually.
  • Generate ranges... — creates ranges automatically from the values occurring in the layer data.
  • Remove all ranges — clears the ranges for the selected field.
  • Symbol gradient... — applies graduated colours, opacity or symbol sizes across the existing ranges.

For each range/category, enter the value or value range and define any symbology properties that should override the base symbol. The symbol sample shows the effective result. Click the sample or Edit to open the symbology editor; use Reset to remove the range-specific override.

Generating ranges automatically

For numeric and date fields, specify the number of intervals and, if required, the minimum and maximum values and rounding. For term-list fields, ranges can be generated from the values currently found in the database or from all terms in the vocabulary.

Using a symbol gradient

The symbol gradient dialog can vary stroke colour, fill colour, stroke opacity, fill opacity and symbol size from a starting value to an ending value. Heurist distributes the values across the ranges already defined for the selected field. Opacity values range from 0 (transparent) to 100 (opaque).

Saving and removing thematic renderers

Click Save thematic map to return the thematic renderer definitions to the layer symbology editor. Each thematic renderer must have a title and at least one field with ranges/categories before it can be saved.

Use the bin icon in the renderer list to delete a thematic renderer. If the final renderer is removed, the editor returns to its initial empty state. You can add another renderer, or save the empty renderer set to remove thematic rendering from the layer.

How symbols are combined

The final symbol for a record is built in this order:

  1. Normal map-layer symbology.
  2. The thematic renderer's optional Base symbol.
  3. Overrides defined by the matching range/category for each thematic field.

This allows thematic fields to modify only selected properties without redefining the complete symbol for every range or category.
