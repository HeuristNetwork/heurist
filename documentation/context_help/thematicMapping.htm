Thematic Mapping

Thematic maps change the appearance of records on a map according to the values of one or more record fields. For example, a field such as Country can control colour, Population can control symbol size, and City type can control the marker symbol.

Opening the thematic map editor

Open the symbology editor for a map layer and choose the thematic maps option. A map layer may contain several thematic map definitions. Use the Thematic maps list to select the definition you want to edit, or use the plus button to add another one.

Thematic map settings

  • Title — the name displayed for this thematic map.
  • Active by default — makes this thematic map active when the map layer is first loaded.
  • Base symbol — optional symbology applied before field-specific rules. Click the symbol sample or Edit to modify it. Use Reset to inherit the layer's normal symbology.

A thematic map can override only the properties that need to change. Any property not specified by the thematic map continues to use the base symbol or the normal layer symbology.

Selecting fields

The Fields list contains the fields used by the selected thematic map. If no field has yet been selected, the field-selection area is displayed automatically. Choose the relevant record type, then select a field from the record structure.

After at least one field has been added, the field-selection area is hidden to leave more space for editing ranges and categories. Click Select another field whenever you need to add another field.

Several fields may contribute different parts of the final symbol. For example, one field can determine colour, another can determine size, and another can determine the icon.

Defining ranges and categories

Select a field in the Fields list to edit its ranges or categories. The field Title can be changed to a more suitable label for use in the thematic map.

  • Add range — adds a range or category manually.
  • Generate ranges... — creates ranges automatically from the values occurring in the layer data.
  • Remove all ranges — clears the ranges for the selected field.
  • Symbol gradient... — applies graduated colours, opacity or symbol sizes across the existing ranges.

For each range/category, enter the value or value range and define any symbology properties that should override the base symbol. The symbol sample shows the effective result. Click the sample or Edit to open the symbology editor; use Reset to remove the range-specific override.

Generating ranges automatically

For numeric and date fields, specify the number of intervals and, if required, the minimum and maximum values and rounding. For term-list fields, ranges can be generated from the values currently found in the database or from all terms in the vocabulary.

Using a symbol gradient

The symbol gradient dialog can vary stroke colour, fill colour, stroke opacity, fill opacity and symbol size from a starting value to an ending value. Heurist distributes the values across the ranges already defined for the selected field. Opacity values range from 0 (transparent) to 100 (opaque).

Saving and removing thematic maps

Click Save thematic map to return the thematic definitions to the layer symbology editor. A thematic map must have a title and at least one field with ranges/categories before it can be saved.

Use Remove theme to delete the selected thematic map. If the final thematic map is removed, the editor closes and returns the remaining ordinary layer symbology, so the thematic mapping is removed from the layer when the parent symbology editor is saved.

How symbols are combined

The final symbol for a record is built in this order:

  1. Normal map-layer symbology.
  2. The thematic map's optional Base symbol.
  3. Overrides defined by the matching range/category for each thematic field.

This allows thematic fields to modify only selected properties without redefining the complete symbol for every range or category.
