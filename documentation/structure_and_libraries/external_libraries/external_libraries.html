Third-party libraries
External software used by Heurist

Last updated: 18 July 2026.

This register identifies third-party software distributed with, loaded by, or used to build Heurist. Installed Composer versions should be checked against composer.lock.

Some legacy libraries contain local modifications. Their upstream licence remains applicable, and modifications should be recorded in documentation/modifications_to_external_functions.txt.
