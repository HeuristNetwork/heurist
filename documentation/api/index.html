Heurist Open API
Open API documentation

The Heurist Open API provides public access to records, database definitions, map and timeline resources, IIIF resources and Web Annotations, with authentication used where access to private data or protected operations is required.

Interactive Swagger documentation Browse endpoints, inspect schemas, authorize with a JWT, and run requests. OpenAPI specification Download the authoritative machine-readable YAML contract. Postman collection Download API examples and the executable regression test collection. Postman environment Download the environment template and replace its placeholder values.
API base URL: ../. Public records, definitions, map resources, timeline data and IIIF resources may be accessed anonymously when the underlying records are public. Private records require authentication.
