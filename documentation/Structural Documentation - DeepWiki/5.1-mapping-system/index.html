The Heurist Mapping System provides comprehensive geospatial visualization capabilities, including interactive maps with timeline integration, layer management, drawing tools, and story mapping functionality. This system enables users to visualize geographic data from Heurist records, create map documents with multiple layers, and build interactive story maps that combine spatial and temporal data.

For information about the broader User Interface framework that contains mapping widgets, see User Interface. For details about the CMS website generation system that can embed maps, see CMS Website Generator.

Architecture Overview

The mapping system follows a layered architecture with the main mapping widget at its core, supported by specialized managers for layers, documents, and UI controls.
