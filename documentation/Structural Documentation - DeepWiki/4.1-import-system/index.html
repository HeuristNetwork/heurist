Purpose and Scope

The Import System provides comprehensive data ingestion capabilities for Heurist databases, supporting multiple data formats and external service integration. This system handles CSV/TSV files, XML/JSON/HML formats, file uploads, and synchronization with external bibliographic services like Zotero and FieldHelper.

For information about data export functionality, see Export System. For file storage and metadata management, see File Management.

System Architecture

The Import System follows a client-server architecture with specialized JavaScript classes handling user interaction and PHP controllers managing server-side processing.
