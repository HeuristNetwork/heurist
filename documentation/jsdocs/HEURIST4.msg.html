Namespace: msg

msg

Provides a comprehensive set of functions for displaying various types of messages, dialogs, popups, tooltips, and progress indicators within the Heurist application. This includes error handling, informational messages, user prompts, modal dialogs for iframe content, and temporary flash notifications.
