Class: HLayout

HLayout(argsopt) → {Object}

new HLayout(argsopt) → {Object}

Factory function for the HLayout object, an older layout management system for Heurist. It initializes based on widget and layout configurations (typically from `cfg_widgets` and `cfg_layouts`). The returned object provides methods to initialize layouts within specified containers, manage widgets, and handle cardinal (pane-based) layouts.
