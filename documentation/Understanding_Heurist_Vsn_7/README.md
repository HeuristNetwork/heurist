# Directory: /documentation/Understanding Heurist (Vsn 7 2026)

## Overview

This directory contains the markdown files generated from the BookStack installation on HeuristRef.net (from July 2026) for the chapters of the new end-user documentation.

This documentation was started by Ian Johnson in April 2024 but shelved because of pressure of administrative work.

It was taken up again by a volunteer group coordianted by the Huma-Num Heurist Co-Tech group from April 2025.

The files are updated automatically in gitHub by a nightly script run through crontab on HeuristRef.net.
