# Directory: /hclient/widgets/editing

## Overview

This directory houses widgets that provide various editing functionalities within the Heuirst application. These include tools for editing temporal objects, themes, translations, code, images, and managing file/folder selections.

## Key files
- `editTemporalObject.js`: Dialog to define complex date (range, approximate)
- `editTemporalObject.php`: Provides the HTML structure and client-side script initialization for the Edit Temporal dialogue.
- `editTheme.js`: Form to fefine Heurist color theme
- `editTheme.json`: JSON configuration for theme editing.
- `editTranslations.js`: Widget for editing multi-language translations
- `editing2.js`: Defines the HEditing class for dynamic form generation and management.
- `editing_exts.js`: Additional functions for editing_input.
- `editing_input.js`: Defines the `heurist.editing_input` jQuery UI widget for form input controls.
- `editorCodeMirror.js`: Provides a wrapper class `EditorCodeMirror` to integrate the CodeMirror editor.
- `imgFilter.html`: Content for imgFilter dialog
- `imgFilter.js`: Provides a UI dialog for defining CSS image filter configurations.
- `selectFile.js`: Widget to select image files or tiled images from various sources.
- `selectFolders.js`: Widget to select folders from a tree.
- `selectMultiValues.js`: Widget to select values from a multiselection list or tree.
