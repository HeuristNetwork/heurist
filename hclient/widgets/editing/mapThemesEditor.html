Thematic renderers Add renderer

Add a thematic renderer to style layer features according to their attribute values. A layer can have multiple renderers, for example one showing population, another showing category or status, and another showing chronology. Only one renderer is displayed at a time, and users can switch between the layer's Default symbology and any defined thematic renderer.

Only one renderer can be active by default. If none is active, the layer opens with its default symbology.

Add fields to this renderer

Fields determine how attribute values change the appearance of map features. Define ranges or categories for a field, then assign the symbol properties to use for matching values.

A renderer may use multiple fields. Each field can contribute a different part of the final symbol: for example, Country can control colour, Population can control symbol size, and City type can control the marker icon. These changes are combined, so you do not need a separate renderer for every visual property.

Select a field on the left to begin. You can add further fields at any time.
