Import IIIF Manifest

Create Heurist records from a registered or uploaded IIIF Manifest

This function imports a selected IIIF Presentation Manifest and creates or updates corresponding Heurist records. It always creates an IIIF Manifest record and imports available IIIF Annotation records. In Full manifest management mode it also imports IIIF Canvas records and links annotations to those managed canvases.

The generated Manifest output is owned by Heurist in both modes. Manifest-level metadata can be edited in Heurist, such as title, description, rights, provider and thumbnail. On re-import, records that have been modified in Heurist are preserved by default and reported separately.

Import / management level
  • Use this mode to annotate an existing IIIF Manifest without managing its Canvas structure in Heurist.
  • Heurist creates or updates a Manifest record for local management and provenance.
  • The Canvas list and Canvas identifiers are preserved from the source Manifest.
  • Annotations are imported, stored and updated in Heurist, linked to the original Canvas URIs.
  • Manifest output can be generated with Heurist annotation pages overlaid on the original Canvases.
  • Use this mode when Heurist should manage the Manifest structure, not only its annotations.
  • Heurist creates or updates Manifest, Canvas and Annotation records from the source Manifest.
  • Canvas list, order and Canvas-level metadata come from Heurist Canvas records.
  • Canvases may reference registered external media resources or uploaded files.
  • Annotations are linked to managed Canvas records and use generated Heurist Canvas URIs in IIIF output.
