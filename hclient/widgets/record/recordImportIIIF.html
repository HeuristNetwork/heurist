Process IIIF Manifest

Create Heurist records from an IIIF Manifest recorded as a File field (local or remote reference)

Process a selected IIIF Presentation Manifest (local file or external reference) and create or update corresponding Heurist records.
An IIIF Manifest record is created and IIIF Annotations specified in the Manifest are imported as Annotation records.

In Full manifest management mode it also imports IIIF Canvas records, linking the annotations to those managed canvases.
The images or other media referenced by those canvases may be external or stored in Heurist.

On re-import, previously imported records that have been modified in Heurist are preserved and reported separately.

  • Heurist stores and modifies the Manifest as well as the annotations.
  • Heurist creates or updates Manifest, Canvas and Annotation records from the source Manifest.
  • Ownership moves to Heurist for the generated Manifest output, Canvas order and Canvas-level metadata.
  • Heurist becomes the sole reference for the Manifest and for the Annotations. The external manifest is deprecated.
  • Media files may still be external registered resources or may be uploaded to the Heurist database.
  • Manifest-level metadata can be edited in Heurist (eg. title, description, rights, provider and thumbnail).
  • Canvas list, order and Canvas-level metadata come from the Heurist Canvas records.
  • Canvases may reference registered external media resources or uploaded files.
  • Annotations are linked to managed Canvas records and use generated Heurist Canvas URIs in IIIF output.
  • Annotates an existing IIIF Manifest without uploading its Canvas structure to Heurist.
  • Only IIIF Presentation API v3 Manifests are supported in annotation overlay mode.
    (v2 Manifests can only be handled through Full manifest management mode, below)
  • Ownership remains split: the source Manifest and its Canvas list remain on the external IIIF provider;
    Heurist stores a local Manifest record and imported or newly created Annotation records.
  • The Canvas list and Canvas identifiers are preserved from the source Manifest.
  • Annotations are imported, stored and updated in Heurist, linked to the original Canvas URIs.
  • Manifest output can be generated with Heurist annotation pages overlaid on the original Canvases.
