Import IIIF annotations

Create IIIF Annotation records from a selected IIIF Manifest

This function imports annotations from one selected IIIF Manifest. The source Manifest is preserved; imported annotations are stored as IIIF Annotation records and linked to a corresponding IIIF Manifest record in Heurist.

On re-import, annotations that have been modified in Heurist are preserved by default and reported separately. Imported annotations that have not been locally modified may be updated from the source annotation JSON.

Import / management level
  • The source Manifest remains externally owned.
  • Canvas list and Canvas identifiers are preserved from the original Manifest.
  • Heurist creates a Manifest record for local management and provenance.
  • Heurist imports, stores and updates annotations linked to the original Canvas URIs.
  • Manifest output can be generated with Heurist annotation pages overlaid on the original Canvases.
  • Use this mode when you want to annotate an existing IIIF Manifest without managing its structure in Heurist.
  • Heurist owns the generated Manifest output.
  • Manifest-level metadata can be edited in Heurist, such as title, description, rights, provider and thumbnail.
  • Canvas list, order and Canvas-level metadata come from Heurist records.
  • Canvases may reference external IIIF Canvases, registered Heurist files or Digital Media records.
  • Annotations are linked to managed Canvas records where available, or to generated Canvas URIs.
  • Use this mode when you want Heurist to manage the Manifest structure, not only its annotations.
