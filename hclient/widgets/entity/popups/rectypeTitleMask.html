The title mask builds a constructed/composite title from fields in the record.
The constructed value is used as the extended title displayed in search results and other lists.
It can also be used in the construction of other titles eg. parent records or relationships.
It is well worth investing time and thought in defining good constructed titles.

Field values are inserted into the title mask by enclosing the field name in [ ]
e.g. [Title], pp. [Start_Page]-[End_Page] might generate: "Alice in Wonderland, pp. 37-39"

Inserting fields: The element names in square brackets MUST match field names for this record type.
Use the tree view of fields on the left to select fields to insert
To insert a literal square-bracket, use two consecutive square-brackets: [[ or ]]

Optional text: Fixed texts can precede the value or replace the value if the value is missing:
e.g. [Starting_date] {\Starting date: \No starting date} will either generate:
"Starting date: 04-11-1974" or "No starting date" if Start_date is empty.

Limit length: To add a character limit to field values, add the count within the optional text specification:
{50 \Text for existing value \Text for missing value} will limit the value, if it exists, to 50 characters followed by an elipsis ...

We strongly recommend putting each field on a separate line for readability (line breaks in the title mask are ignored)

You may use underline, bold, italics, and other simple html in the title.

Build Mask:       Select fields in tree and click button to insert in mask at cursor position
For legibility we strongly advise splitting field specifications onto separate lines (which will be combined in the result)
Use underline, bold, italics liberally to promote readability, and limit length of long text fields eg. {50}
