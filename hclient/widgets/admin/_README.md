# Directory: hclient/widgets/admin

## Overview

This directory contains widgets related to administrative tasks and functionalities within the hclient application. These widgets provide interfaces for managing server configurations, email forms, repository settings, and importing structures.

## Key files
- `emailForm.html`: emailForm.html - content for emailForm widget
- `emailForm.js`: emailForm widget - either creates form or uses a given one.
- `importStructure.js`: importStructure.js - Widget to browse template databases, select record types, individual fields, or individual vocabularies, and import them into the current database.
- `manageServer.html`: manageServer.html - content for manageServer widget
- `manageServer.js`: manageServer.js - Provides a list of server management actions.
- `repositoryConfig.html`: repositoryConfig.html - content for repositoryConfig widget
- `repositoryConfig.js`: repositoryConfig.js - configuration for external repositories
