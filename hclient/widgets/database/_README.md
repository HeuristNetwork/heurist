# Directory: /hclient/widgets/database

## Overview

This directory contains widgets focused on database management tasks within the Heurist admin interface. These include actions like creating, deleting, cloning, registering, renaming, restoring, and verifying databases or database content.

## Key files
- `dbAction.js`: Dialog for performing various database-level actions
- `dbClear.html`: Content of dialog for clearing a database
- `dbClone.html`: Content of dialog for cloning a database
- `dbCreate.html`: Content of dialog for creating a new database
- `dbDelete.html`: Content of dialog for deleting a database
- `dbRegister.html`: Content of dialog for registering an existing database
- `dbRename.html`: Content of dialog for renaming a database
- `dbRestore.html`: Content of dialog for restoring a database from backup
- `dbVerify.html`: Content of dialog for verifying database integrity
- `dbVerify.js`: Popup dialog for database verification actions
- `dbVerifyURLs.html`: Content of dialog for verifying URLs within a database
- `dbVerifyURLs.js`: Verifies URLs in record headers and fields
