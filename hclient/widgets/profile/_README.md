# Directory: /hclient/widgets/profile

## Overview

This directory contains widgets and associated files for managing user profiles. This includes functionality for users to edit their personal details, handle login information (including password reset and SAML), set interface preferences, and manage registration.

## Key files

-   **profileEdit.html**: HTML structure for the user profile editing and new user registration dialog. It includes fields for user details, password management, and captcha for registration.
-   **profileEdit.js**: jQuery UI widget for editing user profiles and registering new users. It handles different modes for registration and editing existing profiles.
-   **profileLogin.html**: HTML structure for the Heurist login dialog. Includes fields for username/password, SAML options, password reset, and registration links.
-   **profileLogin.js**: JavaScript functions for displaying and managing the Heurist login dialog, including standard login, SAML authentication, guest login, and password reset.
-   **profilePreferences.html**: HTML structure for the user preferences dialog, allowing users to configure various personal settings.
-   **profilePreferences.js**: jQuery UI widget for managing user preferences, such as interface style, mapping options, and default search settings.
-   **profileRegMsg.html**: HTML structure for the message displayed to the user after successful registration, confirming the request and providing next steps.
