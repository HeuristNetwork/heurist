Automatic database safeguarding

After a logged-in user opens Explore, Heurist checks whether the interval has passed and the database has changed. If so, it creates a self-documenting safeguard file and deposits it in each selected repository account. The first published deposit obtains a DOI; later deposits become versions of the same item. The archive files are kept restricted because a full database backup may contain private data and repository credentials.

Large files, particularly archives with many images, may be rejected by the recipient's email service.
Services configured here enable the storage and retrieval of external resources such as images, documents, video on/from the external repositories.
