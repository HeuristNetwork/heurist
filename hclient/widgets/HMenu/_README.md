
Directory:    /hclient/widgets/HMenu

Overview:    Heurist widgets - Menu and its dependencies
             
             HMenu.js - menu widget for page navigation, actions and execution of saved filters
             HMenu.css - styles for record list
             HMenuEdit.js - extension for HMenu to compose its content. It is used in CMS editor
             
             HMenuOpts.js - property editor form 
             HMenuOpts.html - html snippet for property editor form 
             
             HMenuPersonal.js - extension for persoanl menu actions (including login, signin, logout)
             HMenuPersonalBtn.html - persoanl menu as set of puttons
             HMenuPersonalMenu.html - persoanl menu as a dropdown
