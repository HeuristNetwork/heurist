# Directory: /hclient/widgets/report

## Overview

This directory contains widgets related to generating and displaying reports within the Heurist system. These include an editor for creating and modifying report templates, and a viewer for rendering reports based on these templates using data from the system.

## Key files

-   **reportEditor.html**: HTML template for the report editor widget. Defines the structure and layout for the report editing interface.
-   **reportEditor.js**: JavaScript for the report editor widget. Provides functionality for editing Smarty report templates, including creating, modifying, and testing templates. It integrates CodeMirror for template editing and provides tools for inserting template variables and patterns.
-   **reportViewer.html**: HTML template for the report viewer widget. Defines the structure for displaying reports.
-   **reportViewer.js**: JavaScript for the report viewer widget. Handles displaying reports generated by Smarty templates. It allows users to select templates, execute them with the current recordset, and provides options for managing reports (edit, delete, import, export, publish, print).
