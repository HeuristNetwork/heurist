# Directory: /viewers/crosstab

## Overview
Provides the functionality for creating, displaying, and interacting with crosstabulation tables (pivot tables) within the Heurist system. This includes the user interface, client-side logic, server-side data handling, and styling.

## Key files
- `crosstabs.css`: Stylesheet for the crosstab viewer functionality. This file contains all the CSS rules for displaying and interacting with crosstabulation tables within the Heurist system.
- `crosstabs.js`: UI and logic for generating and displaying crosstabulation tables. This file implements the client-side functionality for the crosstabs viewer.
- `crosstabs.php`: Main user interface for the Crosstabs viewer. This file provides the HTML structure and initial JavaScript setup for the crosstab analysis tool.
- `crosstabsController.php`: Server-side controller for Crosstabs viewer. This file handles server-side logic for the crosstab viewer.
- `crosstabs_image.png`: Image for the crosstabs viewer.
- `index.php`: Redirects to the main crosstabs viewer page (`crosstabs.php`).
