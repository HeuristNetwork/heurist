Nearly everyone needs database(s) for some part of their work, and Heurist provides a uniquely capable Humanities-oriented approach to building and maintaining databases.

However, since Heurist's user interface is both rich and non-prescriptive, your first reaction after creating a database may well have been "what do I do next?".

We strongly recommend using the Design Worksheet to help structure your database, but also you may wish to follow the introductory videos in the Learn section of our website HeuristNetwork.org (which, incidentally, is generated by a Heurist database) to get a basic understanding of how to configure a Heurist database.

Once you're over the initial hump you will start to see the immense benefits in cost, implementation time, control, retrieval, website publishing and sustainability, which flow from using Heurist (see attached PDF).

Please visit the website (HeuristNetwork.org) to get an idea of the wide variety of projects using Heurist. Heurist is in widespread use and has been actively developed since 2005.

Support

We are extremely responsive and deal rapidly with all bug reports - generally within a day. We don't think we're perfect and readily take on board suggestions for workflow improvements or new features, often implemented within a few days; Heurist development is deeply informed by the emergent needs of the research projects which use it.

For members of the association (see below) we can provide some guidance to help you understand how Heurist fits into your research or management of resources (send a brief description of your project(s) - see the grey box at the end of this email).

Supporting Heurist

Heurist is Open Source on gitHub and the web services we support (HeuristRef.net and Heurist.Huma-Num.fr) are free to use. The project is entirely non-profit, supported by voluntary contributions, occasional consulting, and servers provided by the Australian Research Cloud and by Huma-Num for France/Europe.

Although Heurist is free to use, we have no institutional support and it costs money to run an infrastructure of this complexity. If you continue to make use of Heurist, we ask that you become a member of Heurist Network, the non-profit association which supports and develops Heurist.

Please also include funding for Heurist in your funding applications for projects which use Heurist and/or in institutional budgets.

If every user, project and lab contributes the individual cost is low, and the more we are supported the better we can support you and offer improvements to the system.

History and RoadMap

A Roadmap for upcoming Heurist development and a concise Development history list of improvements and new features since 2018 is available in the Help menu at top right of the main screen.

Major new features (since 2019 - 2023) include a generic method for moving data between databases (even if they have different structures), importing external databases including all relationships, and generating websites with CMS functions which are stored as an integral part of the database and directly embed Heurist functionality. Version 6, released early 2021, is fully compatible with older databases but provides a more intuitive interface designed in collaboration with a professional UX designer; new features include improved filtering functions including an advanced filter builder, structure editing and vocabulary management, remote data lookup in other data services, extensions to website creation including blogs. In 2022 and early 2023 we added single sign-on capabilies, direct links into repositories, improved mapping and visualisation, IIIF services (both as server and consumer, and for annotation of images), and a completely revised temporal recording system (for fuzzy dates).

Sustainability

Heurist's design is inherently sustainable across all databases, providing for long-term backward compatibility (since 2005). As long as the service is maintained on a server, all databases and websites on that server will remain viable. Databases can be easily migrated from one server to another (see below).

Well aware of the large number of French research databases dependent on Heurist, the French Digital Humanities research infrastructure, Huma-Num, established a technical committee (CoTech) in 2025 to run the Huma-Num Heurist server and maintain a production version of the Heurist code, ensuring long term sustainability over and above the work of the Heurist Network association. We are therefore confident in Heurist's medium-term sustainability (5 - 10 years), if not well beyond.

In addition to sustainability of the Heurist services and maintenance of the Open Source code, the Heurist software can generate complete self-documenting archive packages for each database (Publish > Safeguard file, with options to download or push to a selected repository, providing for long term preservation. These files can also be loaded on another server (Admin > Restore database), providing complete portability.
