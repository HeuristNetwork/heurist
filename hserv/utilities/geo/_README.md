# Directory: hserv/utilities/geo

## Overview
This directory provides utility functions and classes specifically for handling geographical data. This may include coordinate conversion, geometric calculations (like encoding or simplifying polylines), or other mapping-related tasks.

## Key files
- `mapCoordConverter.php`: Defines the GpointConverter class for geographic coordinate conversions.
- `mapCoordinates.php`: This file provides a collection of global functions designed to process GeoJSON data.
- `mapEncodePolyline.php`: Provides functions for encoding polylines, suitable for mapping services.
- `mapSimplify.php`: Provides polyline simplification capabilities using a port of the simplify.js algorithm.
