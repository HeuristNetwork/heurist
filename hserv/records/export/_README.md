Directory:    /hserv/records/export

Overview: This directory contains files related to exporting record data in various formats. These classes typically handle the conversion of Heurist records into formats like CSV, JSON, GeoJSON, XML, GEPHI, IIIF, and RDF.

Key Classes:
ExportRecords.php - Base class for export functionalities.
RecordsExportCSV.php - Handles CSV export.
ExportRecordsGEOJSON.php - Handles GeoJSON export (often part of JSON export).
ExportRecordsGEPHI.php - Handles GEPHI format export.
ExportRecordsIIIF.php - Handles IIIF presentation manifest export.
ExportRecordsJSON.php - Handles JSON export.
ExportRecordsRDF.php - Handles RDF export.
ExportRecordsXML.php - Handles XML export.
