# Directory: hserv/structure/search

## Overview
This directory provides functionalities for searching, querying, or retrieving information about the Heurist database structure itself. This might include looking up specific definitions, terms, or exploring relationships within the schema.

## Key files
- `dbsData.php`: Library of functions to retrieve database structure information: record types, field types, and terms defined in the database.
- `dbsDataTree.php`: DEPRECATED: Function to return record type structure as a tree, primarily used for import definitions.
