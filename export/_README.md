# Directory: export

## Overview
This directory contains scripts and utilities for exporting Heurist database content, structures, and search results in various formats. Functionality includes database backups, data exports to JSON, XML (HML), and KML, as well as managing and publishing scheduled reports.

## Subdirectories
-   `dbbackup/`: Scripts for creating and managing database backups and archives.
-   `json/`: Scripts for exporting record structure templates and data in JSON format.
-   `publish/`: Scripts and interfaces for managing and publishing scheduled reports.
-   `xml/`: Scripts for exporting data in HML (Heurist Markup Language) and KML formats.

## Note
Although these functions are mostly Version 3 code, they have been modified to work with the Heurist 4 and later search interface.
